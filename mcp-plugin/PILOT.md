# Founding Tool-call Audit Pilot

**Proposed fixed fee: $1,500 USD.** Contact RJ Marler: rjmarler8@gmail.com.
This is a professional evaluation offer, not an active subscription or checkout.

For one defined workflow, up to two tool contracts and up to 1,000 customer-provided,
redacted intent/call records, deliver:

- A frozen contract and reproducible schema/rules baseline.
- A labeled error analysis of wrong IDs, missing constraints and malformed arguments.
- Optional local embedding diagnostics, with calibration and held-out evaluation
  when the sample supports it; otherwise report NOT_MEASURED.
- A machine-readable report and review of false accepts, false blocks and limitations.
- Cost comparison using supplied token, retry and service-charge records; no ROI
  claim if those records are unavailable. Include audit overhead in net savings.

Agree scope, dataset authorization/redaction, data handling, acceptance criteria,
delivery schedule and payment terms in writing before starting. No live credentials,
production writes or security guarantees are part of this scope. The customer owns
its supplied data; framework licensing is separate. This offer establishes no sale,
reservation, delivery deadline or commitment until mutually agreed.

The near-term question is whether the audit adds value beyond schema validation
alone. If it does not, the report should say so.
