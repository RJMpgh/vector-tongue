# Real-Model Results

**Status: no complete confirmatory run has been analyzed on this branch.**

Pilot 001 was interrupted by provider request limits. Pilot 002 was blocked by
five source responses that reached its preregistered output ceiling. Neither
pilot was embedded or analyzed, and their responses are not reused. This file
will be generated by the preregistered Batch API Pilot 003 in
[`experiments/real_models/`](experiments/real_models/), and will report the
result whether the Vector Tongue hypothesis is supported, null, or contradicted.
Until a complete run is recorded, the repository remains an implemented
experimental protocol rather than an empirical finding.

The generated report will include:

- exact requested and provider-resolved model identifiers;
- prompt, configuration, response, embedding, and code hashes;
- held-out MSE and cosine distance for every translator and baseline;
- paired bootstrap confidence intervals for \(G(f;g)\);
- calibration-pair permutation controls;
- separate exploratory results for each prompt family;
- failures, retries, token usage, estimated cost, and preregistered pass/fail
  criteria.
